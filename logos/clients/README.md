# לוגואים של לקוחות

הקבצים כאן מוכנים לשימוש. **המקורות שהתקבלו נשמרו ב-`brand/clients/`**,
כדי שאפשר יהיה לעבד מחדש אם צריך.

## מה נעשה לכל קובץ

הרקע הוסר לשקיפות והתמונה נחתכה לגבולות הלוגו עצמו. הרקעים היו שונים —
לבן, שחור, ואצל אחד אבן כהה ומרקמית — ובלי הטיפול הזה כל לוגו היה מופיע
בתוך מלבן בצבע אחר.

| קובץ | מקור | מה נעשה |
|---|---|---|
| `histadrut.png` | ההסתדרות הלאומית לוגו.png | רקע לבן הוסר |
| `zeek.png` | Zeek_Logo_Leumit_Purple_RGB.jpg | רקע לבן הוסר |
| `arian-lev.png` | אריאן לב לוגו.webp | רקע לבן הוסר |
| `sandwich-bar.png` | Sandwich Bar logo white 2025-1.png | רקע לבן הוסר |
| `cyberoot.png` | cyberoot logo.png | רקע שחור הוסר |
| `ice-diamonds.png` | ice diamonds logo.jpg | רקע שחור הוסר |
| `michael-shalva.png` | מיכאל שלווה לוגו.jpeg | **נחתך מתוך תמונת קטלוג** והולבן לפי בהירות |
| `kroizer.svg` | קרויזר דיגיטל.svg | הועתק כמו שהוא, כבר שקוף |

`מיכאל שלווה לוגו.jpeg` לא היה לוגו אלא צילום קטלוג עם הלוגו מוטבע עליו.
חתכתי ממנו את הלוגו והפכתי אותו ללבן על שקוף. הוא נראה טוב, אבל אם יש לך
את קובץ הלוגו המקורי — הוא יהיה חד יותר.

## צבע הצ'יפ

לוגו כהה יושב על צ'יפ לבן, לוגו בהיר על צ'יפ כהה. הבחירה נקבעת בקוד
בשדה `light` שברשימה שב-`index.html`:

| צ'יפ כהה (`light: true`) | צ'יפ לבן |
|---|---|
| `cyberoot.png` (לוגו לבן) | `histadrut.png` |
| `ice-diamonds.png` (זהב, נמוג על לבן) | `zeek.png` |
| `michael-shalva.png` (לוגו לבן) | `arian-lev.png` |
| | `kroizer.svg` |
| | `sandwich-bar.png` |

## להוסיף לקוח

שורה אחת ברשימה שב-`index.html`, והקובץ כאן. הרצועה מוכפלת אוטומטית כדי
שהלולאה תיסגר בלי קפיצה.

קובץ שלא נטען מוריד את עצמו מהרצועה, וכל הסקשן מוסתר כשנטענו פחות
משלושה לוגואים — כך שדף בלי הקבצים לא מציג רצועה ריקה.
