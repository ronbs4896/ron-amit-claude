# לוגואים של לקוחות

הרצועה הנעה בדף המכירה נבנית מהרשימה שבתוך `index.html`, בבלוק
"לוגואים של לקוחות". כל שורה שם מצביעה על קובץ בתיקייה הזאת.

**השמות חייבים להיות בדיוק אלה.** הקוד מחפש אותם, ולא סורק את התיקייה.

| הקובץ המקורי | לשמור כאן בשם |
|---|---|
| ההסתדרות הלאומית לוגו.png | `histadrut.png` |
| Zeek_Logo_Leumit_Purple_RGB.jpg | `zeek.jpg` |
| אריאן לב לוגו.webp | `arian-lev.webp` |
| מיכאל שלווה לוגו.jpeg | `michael-shalva.jpeg` |
| קרויזר דיגיטל.svg | `kroizer.svg` |
| cyberoot logo.png | `cyberoot.png` |
| ice diamonds logo.jpg | `ice-diamonds.jpg` |
| Sandwich Bar logo white 2025-1.png | `sandwich-bar.png` |

שמות עם עברית ורווחים עובדים בכתובת רק אחרי קידוד, ונשברים בחלק
מהשרתים. לכן שמות באנגלית, באותיות קטנות, עם מקפים.

## איך זה נראה

כל לוגו יושב בצ'יפ לבן, כמו ברצועת האינטגרציות שכבר בדף. זה מה שמאפשר
לערבב לוגו שקוף, JPEG עם רקע לבן, ו-SVG, בלי שאחד מהם ייראה שבור.

ללוגו שהכיתוב שלו **לבן** צריך צ'יפ כהה, אחרת הוא נבלע. בקוד מסמנים
אותו `light: true` — כרגע רק `sandwich-bar.png` מסומן כך.

## להוסיף לקוח

שורה אחת ברשימה שב-`index.html`, והקובץ כאן. הרצועה מוכפלת אוטומטית כדי
שהלולאה תיסגר בלי קפיצה.

קובץ שלא נטען מוריד את עצמו מהרצועה, וכל הסקשן מוסתר כשנטענו פחות
משלושה לוגואים — כך שדף בלי הקבצים לא מציג רצועה ריקה.
