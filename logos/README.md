| קובץ | מופיע במקום |
|---|---|
| whatsapp.png | WhatsApp Business |
| instagram.png | Instagram DM |
| messenger.png | Messenger |
| sheets.png | Google Sheets |
| make.png | Make |
| calendar.png | יומן פגישות (Google Calendar) |

הלוגואים מוצגים בלבן אחיד על הרקע הכהה, לא משנה באיזה צבע הועלו.
