# תמונות למסכי מוצר ולפרופילים

נבנו מהתוכן של דף המכירה עצמו, באותו מיתוג. יחס 3:2, מעל כל מינימום
שהפלטפורמות מבקשות, וכל קובץ קטן מ-200KB.

| קובץ | מידות | לאן |
|---|---|---|
| `cover.png` | 1500×1000 | תמונה ראשית. שם המוצר וההבטחה |
| `hook.png` | 1500×1000 | הכאב, לפני ההצעה |
| `inside.png` | 1500×1000 | שלושת חלקי הקורס |
| `how-it-works.png` | 1500×1000 | שלושת השלבים, מהחיבור עד ההדלקה |
| `whats-included.png` | 1500×1000 | מה נכלל, ומחיר ההשקה |
| `logo-square.png` | 512×512 | סלוט לוגו ריבועי |
| `logo-wide.png` | 1024×384 | סלוט לוגו מלבני |

הלוגו יושב על רקע כהה מלא ולא על שקיפות, כי הסימן לבן מבפנים ונבלע על רקע
לבן. `logo-mark.png` ו-`logo.png` שבשורש הריפו הם גרסאות השקיפות, לשימוש
מעל רקע כהה בלבד.

מה שחסר וצריך להגיע ממך: צילום מסך אמיתי של שיחה שהסוכן ניהל, ותמונות
המלצה אמיתיות. לא בונים כאלה מהדמיון.

## לבנות מחדש

התבנית היא `slides.html` בתיקיית העבודה של הסשן. כשהמחיר או התוכן משתנים,
מעדכנים שם ומצלמים מחדש ב-1500×1000.
